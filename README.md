# Business-Document-Generation-System-
Developed   an automated document generation system for support document, supporting the   preparation of approximately 30 business documents. Reduced document   preparation time from approximately 30 minutes to less than 1 minute per   document.

## 📌 Project Overview

This project focuses on automating business support document generation using **Google Apps Script, JavaScript, and HTML/CSS** integrated with Google Sheets and Google Drive.

The solution streamlines the document preparation process by automatically retrieving input data, generating standardized documents, and converting them into PDF files.

The automation is designed to minimize repetitive administrative tasks, improve document consistency, and accelerate the overall document preparation workflow.

## 🎯 Project Objectives

- Automate the generation of business support documents.
- Reduce repetitive manual document preparation.
- Standardize document formats and layouts.
- Generate PDF files directly from structured spreadsheet data.
- Improve operational efficiency and document processing accuracy.

## ⚙️ Key Features

### 1. Automated Data Retrieval
- Retrieve document information from Google Sheets.
- Process structured input data dynamically.
- Populate document templates based on spreadsheet records.

### 2. Dynamic Document Generation
- Generate documents using predefined HTML/CSS templates.
- Automatically populate relevant information into document layouts.
- Maintain consistent formatting across generated documents.

### 3. Automated PDF Generation
- Convert generated documents into PDF format.
- Automatically save PDF files to designated Google Drive folders.
- Organize generated documents for easier access and management.

### 4. User-Controlled Automation
- Integrate checkbox-based triggers in Google Sheets.
- Allow users to initiate document generation directly from the spreadsheet.
- Simplify the document generation workflow without requiring manual coding.

## 🔄 Workflow

1. Input document information into Google Sheets.
2. Select the document generation trigger.
3. Google Apps Script retrieves and processes the data.
4. HTML/CSS templates generate the document layout.
5. The document is converted into PDF format.
6. The generated PDF is automatically stored in Google Drive.

## 🛠️ Tech Stack

| Technology | Usage |

## 📈 Business Impact

The automation significantly improves document preparation efficiency:

- Reduced preparation time from approximately **20 minutes to less than 1 minute per document**.
- Achieved approximately **95% reduction in document preparation time**.
- Improved document consistency through standardized templates.
- Minimized repetitive manual input and formatting tasks.
- Simplified document storage and retrieval through Google Drive integration.
